Privacy policy

Last updated: 21 October 2026.

intern-pipeline is a single-user tool. Its only user is its author, Hargen Zheng, and the only Google accounts it connects to are the author's own. This page describes what the tool does with the data it can access.

Data accessed through Google

  • Gmail (read-only). The tool reads messages in the author's own mailboxes to find emails about the author's job applications. It never sends, modifies or deletes mail.
  • Google Sheets. The tool writes the author's application ledger to a spreadsheet the author owns.

How the data is used and stored

  • Message metadata and extracted facts (sender, subject, which application an email belongs to, its status) are stored in a database on a server operated by the author, for the author's use only.
  • No data is shared with, sold to, or transferred to any third party. No data is used for advertising. No data is used to train machine-learning models.
  • Data is kept for as long as the tool is in use and deleted when the author retires it.

Google API Services User Data Policy

intern-pipeline's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from the Google account's third-party access settings.
